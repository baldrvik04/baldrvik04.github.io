La plataforma local de IA que apoya el desarrollo

Diseñé e implementé un entorno local de IA para desarrollo de software y ciberseguridad, integrado con asistentes de programación y ejecutado con Ollama. El RAG aporta contexto del código y del estado registrado de cada proyecto para apoyar programación, diagnóstico y revisión técnica.

Desarrollé el RAG en Python con PostgreSQL/pgvector, Docker Compose y FastAPI. El pipeline recorre los repositorios, excluye archivos sensibles y contenido innecesario, divide el código en fragmentos y genera embeddings con nomic-embed-text. Combina búsqueda semántica y por palabras clave con RRF y selección de evidencia mediante un modelo local. Las respuestas conservan referencias al repositorio, archivo y líneas.

La actualización es incremental: en cada ejecución compara hashes, actualiza el contenido modificado y evita recalcular los archivos sin cambios. Integré Continue mediante una API autenticada y túneles SSH. Diseñé la selección del proyecto activo mediante manifiestos y un adaptador local; su implementación y la ejecución automática de la ingesta siguen pendientes.
